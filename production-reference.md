# KrampusDebate — PowerPoint production reference

Visual foundation for ENGL 101 Project 3, Group 1: The Traditionalists. This is a production guide, not an editable PPTX export or a finished debate script. Headlines remain editable; classmates supply their own research, citations, and spoken arguments.

## Frame and layer specification

Use PowerPoint Widescreen (13.333 × 7.5 inches), equivalent to a 1920 × 1080 reference canvas. Rebuild text as editable text boxes. Keep background, subject, atmospheric overlays, headline, optional supporting statement, and citation in separate layers. Keep essential content at least 96 pixels from the frame edges. Use muted ivory over near-black or cold blue-gray; reserve warm orange for firelight.

Photographic-looking generated visuals are illustrations. Label them as such in the notes and media inventory. They are never historical documentation. Licensed archival images need a source, date, creator, and reuse permission before inclusion.

## Animation timing map and PowerPoint method

These are reproduction targets. Use the delivered site's actual behavior and asset inventory to distinguish completed motion from planned video. Hold the final readable state for the remainder of each scene. Make all entrances interruptible; never make the speaker wait through a long animation.

| Scene | Target motion beats | PowerPoint recommendation |
| --- | --- | --- |
| mask | Black start; 0–2 s light reveal. Presenter input settles the composition and reveals the title over 0.8 s. | Native Fade for darkness/title; Morph for restrained camera push. A genuine turning head or mask removal requires rendered video, not a translated flat mask. |
| proposal | 0–1.2 s dissolve to village; 0.6–1.4 s title entrance; then still. | Fade transition plus native text Fade. A small background crop change can use Morph. |
| roots | 0–1 s match the prior village crop; reveal sourced evidence on input. | Morph between matched crops; native evidence Fade. Use dated, credited archival images only when acquired. |
| authentic | On input, move between material details; each move 0.7–1 s. | Morph duplicated cropped images. Keep masks and bells stationary after settling. Physical rotation needs video or a genuine 3D model. |
| community | 1.2 s warm dissolve; headline settles within 0.8 s; sustained stillness. | Fade transition and text Fade. |
| economy | Presenter-paced sequence: attraction, visitors, businesses; 0.5 s per reveal. | Native Appear/Fade. Keep relationships readable as a static final diagram; no numerical charts. |
| controversy | 0.4 s dark cut; 0.6 s text reveal; still frame for discussion. | Cut/Fade. Avoid strobes or animated injury imagery. |
| position | 1 s return to opening image; 0.8 s headline reveal; stable finish. | Morph if subject/crop matches; otherwise Fade. |
| cross / rebuttal | 0.35 s entrance; no sustained movement. | Fade and editable text. |
| closing | 1.2 s town-to-mask dissolve; 0.8 s final statement entrance. | Fade/Morph; optional embedded background video only if supplied. |
| sources | Immediate stable readable layout. | None. Use clickable citations. |

Reduced-motion version: replace camera motion and atmospheric animation with a 0.15 s fade or immediate cut. Optional scare stays disabled by default and must require a separate deliberate presenter action. Never put it on an ordinary advance click. Audio must start only after presenter input and have a visible mute control.

## Verified research starting points

Checked November 2, 2026. Machine-readable details and claim boundaries are in `sources.json`.

1. [Austrian National Tourist Office — A Raucous Christmas: Winter Traditions in Austria](https://www.austria.info/en-us/inspiration/raucous-traditions/). Useful for living customs and their regional context. Its discussion of origins includes uncertainty; avoid a falsely precise ancient timeline.
2. [Jennifer Billock, Smithsonian Magazine — The Origin of Krampus, Europe's Evil Twist on Santa](https://www.smithsonianmag.com/travel/krampus-could-come-you-holiday-season-180957438/), December 4, 2015. Useful descriptive reporting on carved masks, fur suits, bells, and public processions. Corroborate ancient-history claims separately.
3. [SalzburgerLand Tourismus — Krampus and Perchten](https://www.salzburgerland.com/en/krampus-and-perchten/). Useful for regional costume details and evidence that tourism organizations promote these events. It does not establish economic impact for the assignment's fictional town.

The former Salzburg Christmas-market event URL now redirects to a generic calendar and should not support a specific event claim. Krampus and Perchten customs overlap in some reporting but should not be treated as interchangeable everywhere. The injury scenario comes from the assignment, not these sources.
