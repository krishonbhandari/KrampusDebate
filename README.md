# KrampusDebate — opening statements only

[Open the eight-slide presentation](https://krishonbhandari.github.io/KrampusDebate/) · [Sources and preparation](https://krishonbhandari.github.io/KrampusDebate/sources.html)

Eight 16:9 cinematic opening scenes, totaling 480 seconds. Ethos leads; community/pathos and tourism/logos support preserving the traditional public Krampuslauf. Safety concerns are acknowledged. Later debate rounds use notes, outside the slideshow.

Arrow/Space/click advance or finish motion. Left goes back. Home/End go to endpoints. F fullscreen, M optional audio, V optional mask-removal film on slide 1. Escape skips film/motion. Reduced-motion preference is respected. Audio starts off.

No editor, Firebase, shared sync, saved drafts, version history, settings menu or extra debate chapters. Text and evidence are prepared in PowerPoint using the separate JSON, notes and source files. All visible filler has been removed.

See production-reference.md for eight-slide timings, layers and PowerPoint instructions. Source media remain in assets. Serve over HTTP; GitHub Pages deploys main/root without a build step.
